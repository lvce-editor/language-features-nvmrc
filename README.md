# builtin.language-features-nvmrc

Language support for `.nvmrc` files in Lvce Editor.

The extension currently provides completions for available Node.js versions from
the Node.js release index.

## Contributing

```sh
git clone git@github.com:lvce-editor/language-features-nvmrc.git &&
cd language-features-nvmrc &&
npm ci &&
npm test
```
